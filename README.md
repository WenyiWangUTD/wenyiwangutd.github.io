# Wenyi Wang — Academic Website

Built with [Quarto](https://quarto.org) and published via GitHub Pages.

## How to rebuild this site

1.  Clone this repo: `git clone https://github.com/WenyiWangUTD/wenyiwangutd.github.io.git`
2.  Open the project in RStudio
3.  Edit `.qmd` files as needed
4.  Preview locally: `quarto preview`
5.  Render: `quarto render` (outputs to `docs/`)
6.  Commit and push changes; GitHub Pages serves from the `main` branch, `/docs` folder
